У меня образование в области прикладной математики и опыт работы в аудите. Использую Python для анализа данных, автоматизации отчетности и финансовых исследований.

## Основной проект

### [Оптимизация всепогодного портфеля](https://github.com/levkazakov2002/master_degree_diploma_code)

Мой магистерский исследовательский проект о распределении активов портфеля на российском финансовом рынке. Он объединяет многокритериальную оптимизацию, сравнение исторических показателей риска и доходности, проверки устойчивости и эконометрический анализ.

Репозиторий содержит расчетный ноутбук, данные и документацию на английском и русском языках.
